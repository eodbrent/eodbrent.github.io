# Privacy Policy - HYTS Bot

Privacy Policy – HYTS Bot

Last updated: 1 February 2026

1. Overview

HYTS Bot is a private Discord bot used to monitor and administer a personal Hytale game server.
This Privacy Policy explains how information is handled when using the bot.

2. Information Collected

HYTS Bot does not collect, store, sell, or share personal user data.

The bot may temporarily process the following information solely to function:

Discord user IDs

Discord usernames

Command inputs

Server status information

Server log output

This information is used only at runtime or for short-term troubleshooting and administration purposes.

3. Data Storage

The bot does not maintain a database of personal user data.
Any logging performed is limited to technical diagnostics and server administration and is accessible only to the server owner.

4. Third-Party Services

The bot interacts with Discord’s API and may interact with third-party services (such as mod hosting platforms) solely to perform administrative tasks requested by authorized users.

No personal data is shared with third parties.

5. Data Security

Reasonable precautions are taken to limit access to the bot and the server environment.
However, no system can be guaranteed to be completely secure.

6. Changes to This Policy

This Privacy Policy may be updated at any time. Continued use of the bot constitutes acceptance of the updated policy.

7. Contact

For questions or concerns regarding this Privacy Policy, contact the bot owner via Discord.


HYTS Bot is a private, non-commercial project and is not affiliated with Discord, Hypixel Studios, or Hytale.
